# Licences

This package holds two kinds of files, under different licences.

## Code and metadata

The JavaScript in `dist/` is released under the MIT License, like the rest of
[math-blocks](https://github.com/math-blocks/math-blocks).

## Fonts

The files in `subsets/` are subsets of the fonts below, renamed to
"MathBlocks Math A" to "MathBlocks Math F". The fonts' licences require or ask
for modified versions to be renamed. Each subset keeps its original font's
copyright, trademark and licence entries in its `name` table.

| Folder in `subsets/` | Family | Made from | Licence |
| --- | --- | --- | --- |
| `stix-two-math` | MathBlocks Math A | STIX Two Math 2.02 | [SIL Open Font License 1.1](licenses/OFL-1.1.txt) |
| `latin-modern-math` | MathBlocks Math B | Latin Modern Math 1.959 | [GUST Font License](licenses/GUST-FONT-LICENSE.txt) |
| `tex-gyre-bonum-math` | MathBlocks Math C | TeX Gyre Bonum Math 1.005 | [GUST Font License](licenses/GUST-FONT-LICENSE.txt) |
| `tex-gyre-pagella-math` | MathBlocks Math D | TeX Gyre Pagella Math 1.632 | [GUST Font License](licenses/GUST-FONT-LICENSE.txt) |
| `tex-gyre-schola-math` | MathBlocks Math E | TeX Gyre Schola Math 1.533 | [GUST Font License](licenses/GUST-FONT-LICENSE.txt) |
| `tex-gyre-termes-math` | MathBlocks Math F | TeX Gyre Termes Math 1.543 | [GUST Font License](licenses/GUST-FONT-LICENSE.txt) |

The GUST Font License is the [LaTeX Project Public License 1.3c](licenses/LPPL-1.3c.txt)
plus a request to rename modified versions.
